¿Que es un array/arreglo?
Es una estructura de datos

Imaginemos que es como una cadena

[1, 2, 3, 4, 5, 6, 7] que tienes eslabones, y cada esabón tiene una posición específica. El primer eslabón de la cadena siempre va a ser el primero, y así sucesivamente


Un array es como una lista de datos, uno despues del otro, con posiciones.

Ejemplo sin array:

let alumno1 = "Kiara"
let alumno2 = "María"
let alumno3 = "violeta"

Ejemplo con array:

let alumnos = ["Juan", "Pedro" "Fernando"]
es mas ordenado, escalable y real.


Cosas importantes:

-Es como una cadena de datos, un dato, siguiendo al otro
-Los arrays pueden contener múltiples tipos de datos, es indiferente a esto.
-Un array puede estar dentro de otro array, y asi indefinidamente
-Pueden estar mezclados los tipos de datos
-Cada uno de estos datos cuenta con una posición definida y específica
-Cada una de estas posiciones, se llama INDICE
-Se considera al array como un tipo de dato en sí
-Cuando se cuenta los índices de un array, SIEMPRE el primer índice es el índice 0


-----------------------------------------------------------------------------

Métodos comunes:

push ->      Agrega un elemento al final
pop ->       Elmina un elemento al final
unshift ->   Agrega elemento al principio
shift ->     Elimina elemento al principio


Metodo         Que hace                 Donde

push           Agrega elemento          Al final
unshift        Agrega elemento          Al principio
pop            Elimina elemento         Al final
shift          Elimina elemento         Al principio


length -> Indica el largo de un array
